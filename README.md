# หน้ารีวิวแอฟฟิลิเอต น้องมิว Mew Story

เว็บสาธารณะ: https://glasskitchenware-cmd.github.io/mew-review/

รีโปนี้เป็นคนละชุดกับ `mew-storefront-picks` และไม่ได้ทับรีโปเดิม

## สิ่งที่หน้านี้ทำ
- แสดงสินค้าจาก `products.csv` เฉพาะแถวที่ลิงก์ขึ้นต้นด้วย `https://s.shopee.co.th/`
- เปิดเผยว่าเป็นลิงก์แอฟฟิลิเอต
- แสดงข้อความ **ข้อมูล ณ วันที่** ตามคอลัมน์ `checked_at` ของแต่ละสินค้า
- ไม่แต่งรีวิว ไม่รับประกันยอดขายหรือรายได้ และไม่แสดงค่าคอม

## การอัปเดตรายวัน (ฟรี ไม่ใช้ AI)
GitHub Actions ชื่อ `Daily rebuild` รันทุกวันเวลา 09:00 เวลาไทย (`cron: 0 2 * * *` ตาม UTC) และกดรันมือได้

ขั้นตอนของจอบ:
1. รัน `refresh.py` เพื่อลองแหล่งข้อมูลสาธารณะฟรี
2. ถ้าดึงราคาสดไม่ได้ จะไม่แก้ราคาใน CSV และไม่เดาราคา
3. รัน `build.py` สร้าง `index.html` ใหม่
4. ถ้าไฟล์เปลี่ยน จะคอมมิตกลับเข้า `main`

## วิธีอัปเดตรายการสินค้า
แก้ `products.csv` แล้วพุช หรือวางไฟล์ใหม่แล้วรัน workflow ห้ามใส่คอลัมน์ค่าคอมลงในไฟล์นี้

ชีตภายในของทีมยังไม่ถูกดึงอัตโนมัติ เพราะยังไม่ได้เผยแพร่ CSV สาธารณะ และชีตต้นทางมีคอลัมน์ค่าคอมภายในที่ห้ามขึ้นเว็บ

## สิทธิ์
ผลงานและลิงก์เป็นของช่องน้องมิว Mew Story
